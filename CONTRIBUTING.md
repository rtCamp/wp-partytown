# Contributing to wp-partytown

Thank you for your interest in contributing to wp-partytown.

This document provides simple guidelines to help maintain code quality and consistency.

## How to Contribute

1. Fork the repository
2. Create a new branch from `main`
3. Make small, focused changes
4. Submit a Pull Request

## Pull Request Guidelines

- Keep changes minimal and relevant
- One improvement or fix per Pull Request
- Avoid unrelated formatting or refactoring
- Clearly describe what the PR does

## Commit Message Format

Use clear commit messages such as:

feat(docs): add contributing guidelines  
fix(core): handle missing script attributes  
chore: update documentation

## Coding Standards

- Follow WordPress coding standards
- Use descriptive variable and function names
- Prefer WordPress hooks and filters
- Add comments when logic is not obvious

## Testing

If your change affects functionality:
- Test locally in a WordPress environment
- Ensure no PHP or JavaScript errors occur

## Questions

If unsure about a change, please open an issue for discussion before submitting a Pull Request.
